# AICraft 注塑工艺优化 — Dify 官方工具插件

为 Dify 智能体（Agent）、对话流（Chatflow）与工作流（Workflow）提供工业级**科学注塑（Scientific Molding）**计算能力，底层由自研物理模型与模糊专家规则引擎驱动（`https://aicraft4injection.com`）。

## 包含工具

| 工具名称 | 接口 | 额度消耗 | 功能说明 |
|---|---|---|---|
| **首模工艺设定** (`first_shot_setup`) | `POST /v1/first-shot` | 1 次调用 | 根据材料牌号/物性、壁厚/流长/投影面积、总射重及注塑机螺杆规格，物理推算料筒/模具温度、多级射胶速度/压力/位置、V/P 切换点、保压、储料松退、冷却时间与工艺窗口裕度。 |
| **试模缺陷调优** (`optimize_defect`) | `POST /v1/optimize` | 1 次调用 | 针对短射、飞边、缩水、翘曲、烧焦、熔接痕等 25 种注塑缺陷，结合机台 6 项实测值进行模糊推理与安全门控调优，输出调优前后增量对比表。 |
| **字段与缺陷目录** (`get_schema_catalog`) | `GET /v1/schema` | **免费（0 次）** | 查询完整的工艺参数代码释义、默认单位、25 种标准缺陷码与调用示例。 |

## 快速配置

1. 前往 **https://aicraft4injection.com** 订阅获取专属 API Key（`sk_...`，\$19/月含 1,000 次调用；参数校验报错与目录查询不扣额度）。
2. 在 Dify 安装本插件后点击 **授权 / 配置凭证**，填入 `sk_...` 密钥并保存（凭证校验不消耗调用额度）。

## 推荐两步闭环用法

1. **开模前首模推荐 (`first_shot_setup`)**：传入材料简称（如 `PC`）、平均壁厚（如 `2.0` mm）、螺杆直径（如 `36` mm）、**总射重 `target_shot_weight_g`**（含流道克重，如 `62` g，物理计算螺杆行程必填）以及业务编号 **`business_id`**（如 `MOLD-2026-001`）。
2. **试模后缺陷调优 (`optimize_defect`)**：传入同一个 **`business_id`**（或首模返回的 `process_no`）+ 观察到的缺陷代码（如 `SHORTSHOT`）+ 严重程度（`moderate`）及机台实测读数，服务端会自动调出上一模档案并给出参数调整增量表。
